2. BẢNG MÀU CHỐT: XANH TRỜI HY VỌNG (OCEAN AZURE & COBALT)
- Tông màu xanh biển Cobalt & Azure tươi sáng, trong trẻo, mang ý nghĩa bầu trời rộng mở vạn dặm
  "Tung cánh bay xa" của Tân Kỹ Sư.
- Đã khóa cố định màu Xanh Hy Vọng và dọn dẹp sạch mã của các bảng màu cũ.
- Đã bỏ hoàn toàn phần lịch trình buổi lễ theo yêu cầu.

3. KHẮC PHỤC TRIỆT ĐỂ LỖI FONT TIẾNG VIỆT 100%:
- Thay thế hoàn toàn bằng bộ Google Fonts chuẩn quốc tế có vietnamese subset đầy đủ:
  + Montserrat: Font in hoa học viện trang trọng, chữ số và tiêu đề sắc nét chuẩn 100%.
  + Be Vietnam Pro: Font chữ chuyên biệt cho tiếng Việt của người Việt, dấu thanh không bao giờ bị lệch.
  + Playfair Display: Tiêu đề danh giá, quý phái.
  + Dancing Script: Chữ ký mềm mại, dấu sắc/huyền/hỏi/ngã/nặng hiển thị mượt mà tự nhiên.

4. HIỆU ỨNG ĐẶC BIỆT TRÊN ĐIỆN THOẠI DI ĐỘNG:
- Nghiêng 3D bằng cảm biến con quay hồi chuyển điện thoại (Gyroscope).
- Vệt sáng phản quang Hologram óng ánh khi nghiêng máy.
- Vệt bụi sao và pháo hoa mini khi chạm ngón tay vào màn hình (Touch Particle Engine).
- Rung xúc giác haptic khi mở thiệp và khi tương tác.
- Chạm nút tung nón cử nhân 🎓 và pháo hoa kim tuyến rực rỡ.

5. CÁCH TẠO LINK RIÊNG TỪNG NGƯỜI (CÁ NHÂN HÓA THIỆP MỜI):
Hệ thống hỗ trợ 2 cách vô cùng linh hoạt:

- CÁCH 1: Bạn gửi danh sách tên vào tin nhắn cho AI
  -> AI sẽ tự động chuẩn hóa, nạp vào file `config.js` và gửi lại bảng link hoàn chỉnh cho bạn!

- CÁCH 2: Dùng công cụ tạo link có sẵn tại `tao-link.html` (hoặc `domain.com/tao-link`)
  -> Chỉ cần dán danh sách tên (mỗi người 1 dòng), bấm "Tạo danh sách link".
  -> Có sẵn nút Copy Link, Copy tin nhắn Zalo kèm tên và link của từng người trong 1 giây.

HỖ TRỢ 2 DẠNG LINK:
  + Dạng link đẹp: domain.com/anh-nam , domain.com/bac-ba
  + Dạng link tức thì (Khuyên dùng): domain.com/?to=Anh+Nam

6. CƠ CHẾ LƯU LỜI CHÚC VÀO FILE WISHES.JSON:
- File `wishes.json` nằm ngay trong thư mục gốc của dự án.
- Chạy server nội bộ: gõ lệnh `node server.js`
  -> Server siêu nhẹ không cần cài thêm thư viện, tự động phục vụ web tại http://localhost:3000
  -> Mọi lời chúc khách gửi qua form sẽ được tự động ghi thẳng vào file `wishes.json`!
- Trong trang `tao-link.html`:
  + Tự động tải dữ liệu từ file `wishes.json`.
  + Nút [📥 Tải wishes.json]: Lưu file JSON về máy tính.
  + Nút [📤 Nạp file JSON]: Tải file wishes.json từ máy tính lên xem trực tiếp.
  + Nút [💻 Xem mã JSON]: Hiển thị mã JSON thô để copy/paste nhanh.
